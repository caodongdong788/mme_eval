# 归因诊断体系优化实施计划

## 目标

在不改变八维与指南评分公式的前提下，把归因从“单次大模型解释扣分”升级为：

1. 判分健康检查；
2. 原子扣分复核；
3. 基于完整对话、调用链与完整 RAG 审计的因果诊断；
4. 跨 Case 根因聚类；
5. 带风险、验证方法和验收条件的优化方案。

## 兼容边界

- 保留 `AttributionTask` / `AttributionTaskItem`、三并发、逐条落库、续跑、取消和历史任务快照。
- 保留完整 RAG all / qualified / candidate / selected 证据，不裁剪文献集合。
- 不修改八维、指南、医学安全门禁和 45 分汇总逻辑。
- 新字段均保持可选，前端兼容 v3 历史归因结果。

## 实施步骤

1. 指南扣分作为原子问题；八维作为结果汇总，仅在无对应指南扣分时生成未映射维度问题。
2. 确定性检测 Judge 执行异常、八维结果缺失/重复、重复评测不稳定、Rubric 维度缺失和扣分证据缺失；无效判分不调用归因模型。
3. v4 归因输入显式携带 Rubric 合约、期望/实际差距、运行配置血缘和可观测性状态。
4. 归因输出固定为 cx-agent 问题、评测复核、证据不足三类，并提供反事实根因、风险和验收标准。
5. 基于已落库 Case 结果按责任模块和根因聚类，生成任务级影响面和回归验证计划。
6. 前端增加判分健康提示、期望—实际—差距、任务级问题簇与结构化优化方案。
7. 增加后端聚合/异常隔离测试和前端兼容测试，完成全量构建验证。
