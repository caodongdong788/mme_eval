# 改判据结构化编辑计划

## 目标

- 用例明细的“改判据”不再展示或编辑 YAML 文本。
- 复用 benchmark 用例的结构化编辑界面，按基本信息、用户档案、对话、八维要求和指南扣分点可视化展示。
- 保留单用例试判与覆盖当前 benchmark 的现有业务动作。

## 实施

1. 从 benchmark 用例抽屉中提取可复用的结构化编辑内容组件。
2. 新增用例明细专用结构化改判据抽屉，不提供“查看源 YAML”入口。
3. 用例明细打开编辑器时直接读取当前 benchmark 的结构化 Case 内容。
4. 试判通过结构化 `case_override` 提交判据；覆盖时保存结构化 Case 并沿用确认提示。
5. 清理用例明细中的 YAML 编辑状态和文案。

## 校验

- 新增结构化改判据抽屉的交互测试。
- 前端类型检查、Lint、全量测试与生产构建。
- 完成后更新 Graphify 图谱。
