# 指南判定理由两段式展示计划

## 目标

- 扣分项的判定理由固定拆成“扣分理由”和“扣分原文”两段。
- 扣分理由使用红色强调；扣分原文支持 Markdown，保留 bot 原话中的重点标记。
- 判定理由列不再重复展示检查点、遗漏项和扣分规则。
- 新评测的 Judge 输出直接遵循简洁理由与原文证据的约束。

## 实施

1. 重构指南评分表的判定理由单元格，按是否扣分选择两段式或普通结论展示。
2. 从判定理由列移除 `missed_points`，检查点与规则只保留在首列。
3. 使用 Markdown 渲染 `evidence` 中的 bot 原文。
4. 更新 Guideline Judge 提示词，禁止在 `reason` 中复述检查点、编号和扣分规则。
5. 补充前端展示测试与 Judge 提示词测试。
