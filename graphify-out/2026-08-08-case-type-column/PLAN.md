# 用例明细类别字段切换计划

## 目标

- 用例明细表“类别”统一展示评测 YAML 中的 `case_type`，不再复用 `scenario`。
- 新评测在单条结果落库时保存 `case_type`，列表接口直接返回该标量字段。
- 既有评测从冻结在 `detail_json` 中的 Case YAML 快照回填 `case_type`，缺失时展示为空态。
- 表格的“类别”筛选项与展示字段保持同一数据源。

## 实施

1. 为 `case_result` 增加 `case_type` 标量列，并扩展轻量数据库迁移与历史回填。
2. 在 Case 结果构造、接口响应模型和前端类型中贯通 `case_type`。
3. 将用例明细表和筛选器的“类别”字段切换到 `case_type`。
4. 补充后端落库/历史提取测试和前端表格/筛选测试。

## 校验

- 后端相关测试与全量测试。
- 前端类型检查、Lint、单测和生产构建。
- 完成后刷新 Graphify 图谱。
