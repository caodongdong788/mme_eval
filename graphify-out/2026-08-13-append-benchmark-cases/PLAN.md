# Append Benchmark Cases

## Goal

- Benchmark 库每条已上传评测集增加“追加”操作。
- 支持从 YAML、含图片 ZIP 或飞书 URL 向现有评测集追加用例。
- 保留目标评测集名称、用途、默认对话模式和来源属性。

## Safety

- 新旧用例 `sample_id` 重复时拒绝整次追加，不覆盖原用例。
- ZIP 图片路径与已有文件冲突时拒绝整次追加。
- 先在暂存目录生成并校验完整合并结果，再原子替换目标目录。

## Verification

- 后端覆盖 YAML 追加、重复 ID、ZIP 图片及图片冲突。
- 前端覆盖操作入口、追加弹窗及提交 API。
- 运行相关后端测试、前端测试和生产构建。
