# 项目级 Skills

项目自带 Skill 位于 `.codex/skills/<name>/SKILL.md`，由 Codex 在相关任务中按需使用。

| Skill | 用途 |
|---|---|
| `frontend-design` | 前端页面与组件设计 |
| `graphify` | 关键架构/评分链路的静态增量图谱与依赖查询（非每次提交） |
| `impeccable` | 前端 UX、视觉与无障碍优化 |
| `writing-plans` | 多文件或高风险任务的实施计划 |
| `ponytail` | 优先最小实现，控制复杂度 |
| `ponytail-review` | 检查过度设计与可删除代码 |
| `ponytail-help` | Ponytail 使用说明 |

Skill 在新会话开始时加载；增删后请新建 Codex 任务。
