# 评分标准页面与 Judge 标准同步计划

## 目标

- 以 `medeval/evaluation.py` 作为八维定义、角色归属、判定细则和通用分档的单一真值源。
- Judge prompt 与 `/api/config/evaluation-standard` 均从该真值源生成，移除重复维护的八维细则。
- 页面按角色分组展示八维标准、评分范围、Gate、通用分档、评级和指南扣分规则。
- 保留现有评测公式与 45 分制，不改变历史得分语义。

## 实施

1. 扩充统一标准定义，使其完整覆盖 Judge 当前使用的 0 分/5 分边界。
2. 将 Judge prompt 的固定八维细则改为动态注入，并为动态生成增加测试。
3. 扩展评分标准接口，回传角色标签、通用评分锚点和可读的指南规则。
4. 重做评分标准页面，使用平台 Dashboard Surface 组件与响应式分组布局。
5. 运行相关 pytest、前端测试、类型检查和生产构建。
